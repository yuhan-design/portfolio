美股放大鏡網站改版

針對台灣美股散戶與新手投資人，透過認知走查、競品分析與使用者訪談，重新改版首頁、梳理個股頁資訊架構並補全財報資料缺口。在優化前端效能與體驗後，成功將平均停留時間從 46 秒提升至 50.6 秒（+10%），並推動重點站台 SEO 排名從 13.8 名躍升至 6–7 名，週流量成長 22–36%。

產品類型

美股股市資訊網站

專案週期

2025/03–06

目標用戶

美股投資初學者

研究方法

認知走查、競品分析、使用者訪談、功能優先級矩陣

Goal

目標與背景

美股放大鏡是一個面向台灣投資人的美股股市資訊與財經新聞平台，提供個股頁、財報分析、AI 摘要等功能。隨著競品平台功能逐漸完善，站內 SEO 排名下滑，用戶留存率偏低。

本次設計任務聚焦於首頁、個股頁的完整優化，目標是透過資訊補全、架構重整並調整閱讀動線與效能提升，解決投資人在站內無法完成「看懂一支股票」的核心體驗斷點。

Objective

解決用戶進站與產品體驗，提升重點站台 SEO 排名

Key Result

提升美股放大鏡個股頁體驗，排名進前 10 名，新增 PV、工作階段數與停留時間提升

Process

設計流程

先以認知走查釐清問題，再依實際使用習慣重新定位架構規劃的依據。

認知走查

逐一走過個股頁的關鍵任務流程，統整目前資訊架構與畫面上的問題

競品分析．架構規劃 v1．設計初版

比較站內外美股資訊平台，找出功能落差，並產出第一版資訊架構與設計稿來評估閱讀動線

美股研究員／投資者訪談

提供畫面給訪談者，深入了解內部研究員與美股 PM 的實際使用習慣，作為本專案最關鍵的架構調整依據

架構規劃定案

根據現有數據評估各項數據點擊量，並考量工程人力與美股放大鏡目前的低流量現況，決定先補齊重要數值，而非一次做滿所有競品功能

設計精稿 → 工程開發

完成高保真設計稿並交付工程實作

Research

研究方法

透過四種互補的研究手法，從不同角度收斂問題真相，避免單一方法帶來的視角盲區。

目前個股頁的問題（實際畫面）

與競品相比，我們目前缺乏的功能

  • 財報分析資訊不足：缺少完整的三大財報資料（損益表、資產負債表、現金流量表）✓
  • 即時數據與走勢關鍵值缺乏：如昨收、開高低收等即時行情關鍵指標✓
  • 個股比較功能：無法並列比較多檔股票的財務與走勢表現
  • SEC 13F 機構持股報告：缺乏機構投資者的持股變化資訊
  • 策略選股指標：缺少可作為買進依據的篩選條件或策略指標
  • 分析師目標價與評級預測：無分析師對個股的預期與評價
  • 名人持股資訊：缺少投資名人或機構持倉公開資料

優先方向

根據站內可取得的資料，現階段優先補強基礎資料的完整性，完整財務報表內容、關鍵走勢數據。

美股研究員

寫美股分析的內容作者

  1. 期望財務比率與預估EPS數據能夠清楚呈現
  2. 盈餘預估對用戶對公司表現的認知有顯著影響
  3. 新聞依時間順序顯示，提升使用體驗
  4. 會先看走勢/K線後，再看新聞是發生什麼事，對應到實際公司的獲利狀況或營收，往下看大家隨意討論的內容
  5. 常看 Seeking Alpha 的未來幾季營收與預估EPS，數值可以反映未來
  6. 一般數值會有年/季切換，多達5-10年或近8季的時間長度
  7. 除權在美股上沒這概念，通常稱呼股利，美股投資一般不看股息這塊，因為手續費高
  8. 關鍵數值上原殖利率改為本淨比比較好(營收也可以但屬於比較固定的值)
  9. 想看 non-GAAP 資料
  10. …

美股投資者

投資台股也研究美股的投資人

  1. 台灣投資人只熟悉巴菲特(根據加上巴菲特字眼點擊率會較高來看)，其他大戶持股較不熟悉，至於管理層持股資料，公司目前沒有也覺得沒必要
  2. 走勢跟K線會互相比較，比較熟的股票會直接看K線也不特別研究財報
  3. 不認識的股票看完K線/走勢後對應新聞，再看一下基本介紹了解公司
  4. 希望K線圖能清楚標註現在2024/2025年區隔以及對應的重大新聞，例如財報公布等影響走勢的標註
  5. 台灣投資的慣性會查看股利，因為台股的關係，就算美股手續費高，也還是會習慣點擊，除權息是台股投資人習慣的名字
  6. 本益比可以用河流圖顯示
  7. …

根據訪談回饋，美股研究員需產出文章內容，對數據的完整性與預測性有較高需求；而一般投資者則習慣以台股操作邏輯看待美股，較依賴K線圖與新聞摘要，多數僅關注少數熟悉的大型公司，對資料的研究深度相對較低

Problem

發現的問題

研究收斂後，識別出三個根本性設計問題，彼此相互強化，共同造成用戶高跳出率。

1
高衝擊 資料完整性

個股頁資訊量嚴重不足

財報圖表存在大量缺值，三大財報（損益表、資產負債表、現金流量表）資料不完整，即時行情關鍵指標（昨收、開高低收）完全缺席，導致投資人無法在站內完成基礎研究決策。

2
中衝擊 資訊架構

閱讀結構混亂，資訊優先序錯位

AI 摘要區塊被置於財報圖表之前，破壞使用者由「基本面 → 輔助解讀」的自然閱讀流。區塊排列缺乏層次，散戶在尚未建立基本認知的情況下先接收 AI 結論，反而增加困惑感。

3
中衝擊 可擴充性

展開式佈局不利資訊擴充

初期為填滿畫面，所有區塊一律採展開式排列（accordion always-open）。隨資料量成長，頁面長度急遽增加，導致滾動體驗惡化，且無法為新增資訊類型建立合理的視覺容器。

Solution

解決辦法

三個解決方向對應三個問題根源，優先處理資料完整性，再逐步重構架構與強化效能。

📈 01

補全三大財報＋即時行情

  • 完整實作損益表、資產負債表、現金流量表三大財報的資料串接與視覺化
  • 新增即時行情欄位：昨收、開盤、最高、最低、收盤等關鍵走勢指標
  • 依站內可取得資料排列優先補強順序，確保基礎資料完整性先行
🗂️ 02

重構資訊架構與閱讀優先序

  • 將財報數據與走勢圖表前置，AI 摘要移至「解讀輔助」層，符合投資人自然決策流程
  • 採用 Tab 式導航取代展開式排列，讓不同資訊類型各有獨立容器，頁面長度可控
  • 透過視覺層級（字型大小、色系、間距）強化資訊層次感
⚡ 03

前端效能優化・QPS 1,200

  • 優化前端渲染效能與 API 呼叫策略，使個股頁承載力從現況提升至 QPS 1,200
  • 搭配 SEO 結構化資料（Schema Markup）優化，讓財報數據被搜尋引擎正確索引
  • 頁面載入速度提升間接改善 Core Web Vitals，進一步強化 SEO 排名訊號
